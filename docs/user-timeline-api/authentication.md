# Authentication

All API requests require authentication credentials.

Include the required API authentication headers when making requests.

To access the API use the client-based credentials, client-Id and client-secret. Log in to the ABC application and from the Settings menu, navigate to the API Management page to generate API credentials, client-Id and client-secret. For more details, see <hyperlink: API Management>.

## Security: HTTPS
The data remains encrypted and protected from unauthorized access while transmitting between the clients and servers, thereby ensuring overall system security.

## Content-Type

application/JSON

This API supports the content to be sent and received in the format of JSON data.
