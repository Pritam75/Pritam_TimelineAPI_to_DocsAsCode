# Overview

User Timeline API retrieves the session associated with a Viewer ID, Session ID or combination of both. It provides our customers with real-time self-validation capabilities for the SDK integrated into their application. This API enables customers to automate the validation of SDKs integrated with applications running on Mobile (Android, iOS) and Web (JavaScript).

The User Timeline API offers a straightforward, efficient, and secure approach to gathering session summaries, event timelines, and metadata, thereby facilitating real-time anomaly detection.

The API supports:

- Timeline event retrieval
- Validation monitoring
- Streaming data diagnostics
- Time-range filtering
